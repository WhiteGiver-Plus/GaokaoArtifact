# 稳定收益流派 Tag 建议稿

本文档只做 tag 重构建议，不修改 `data/artifacts.json`。

判断标准：

- 能形成重复收益，而不是单张牌的一次性效果。
- 有清晰构筑方向：拿到同流派卡后，继续拿同流派卡通常会更强。
- tag 应描述流派，不描述纯机制位置，例如 `压轴题`、`前期题`、`容量` 这类更适合作为说明或隐藏分类。
- 每个流派分为核心卡和次要卡。核心卡是流派收益、发动机或关键转化；次要卡是辅助、桥接、风险牌或局部增强。

## 推荐稳定流派 Tag 清单

- `正确率流`
- `错题连败流`
- `连胜流`
- `胜败交替流`
- `销毁抽取流`
- `豌豆连招流`
- `体力流`
- `分数形态流`
- `无效遗物流`

`幸运方块流` 当前不建议作为稳定收益 tag：虽然有专属强化，但触发仍然高度随机，更像彩蛋/爆发组件。若以后增加保底、频率叠加、触发复制等稳定化卡牌，可以再升格为正式流派 tag。

## 正确率流

收益逻辑：提高正确率，稳定获得题目基础分；正确率溢出后还能转成倍率收益。

核心卡：

- 尤里卡 (`eureka`)
- 强运 (`strong_luck`)
- 小保底 (`small_pity`)
- 大保底 (`big_pity`)
- 押题 (`prediction`)
- 圣水采集器 (`holy_water_collector`)
- 超凡入圣 (`transcendent`)
- 快乐小花 (`happy_flower`)
- 钢笔尖 (`pen_nib`)

次要卡：

- 观星 (`astrology`)：前两题强保障，偏局部正确率。
- 深度思考中 (`deep_thinking`)：正确率收益强，但消耗体力。
- 复活甲 (`guardian_angel`)：提供容错，不直接提高长期正确率。
- 红骷髅 (`red_skull`)：低体力时补正确率，可和体力流交叉。
- 轮回之终末 (`final_reincarnation`)：极端正确率卡，但带强负面。

不建议放入本流派：

- 豆包 (`doubao`)：降低正确率，应该进错题/风险相关流派。

## 错题连败流

收益逻辑：主动或被动降低正确率，通过答错、连错、全错、错题过程分获得补偿或倍率。

核心卡：

- 自刎归天 (`self_sacrifice`)
- 空城 (`empty_city`)
- 过程分 (`process_points`)
- 败兵必哀，哀兵必胜 (`sad_loser`)
- 医死的人越多，医术越高明 (`doctor_scaling`)
- 第五人格 (`identity_v`)

次要卡：

- 豆包 (`doubao`)：降低基础正确率，是错题流启动件。
- 对的对的，哦不对不对 (`right_then_wrong`)：制造错误，但触发次数有限。
- 玻璃大炮 (`glass_cannon`)：过程分和错题倍率可受益，但本身是体力/倍率风险牌。

注意：

- 复活甲 (`guardian_angel`) 和本流派冲突较明显，不建议标为错题连败流。
- 错题流和正确率流应该尽量分开，否则同 tag 抽取会把方向拉乱。

## 连胜流

收益逻辑：连续答对后获得题目倍率、总分倍率或后续题收益。需要正确率流作为上游支撑。

核心卡：

- 羊刀 (`rageblade`)
- 至终的仪式 (`final_ritual`)
- 连坐制 (`linked_seats`)

次要卡：

- 大保底 (`big_pity`)：帮助关键题保持连胜。
- 小保底 (`small_pity`)：周期性保连胜。
- 押题 (`prediction`)：提高稳定连胜概率。
- 快乐小花 (`happy_flower`)：周期性正确率和倍率，适合连胜流。
- 钢笔尖 (`pen_nib`)：关键题爆发，适合连胜流。

风险/不建议作为核心：

- 胜兵必骄，骄兵必败 (`proud_winner`)：虽然由答对触发，但后续降低正确率，会破坏稳定连胜。更适合放在胜败交替流或风险组件里。

## 胜败交替流

收益逻辑：利用“上一题结果”和“本题结果”交替，获得考试倍率。当前卡量较少，但方向明确。

核心卡：

- 前功尽弃 (`all_for_nothing`)
- 知错能改 (`learn_from_mistakes`)

次要卡：

- 胜兵必骄，骄兵必败 (`proud_winner`)：答对后压低后续正确率，帮助制造对错交替。
- 败兵必哀，哀兵必胜 (`sad_loser`)：答错后提高后续正确率，帮助制造错对交替。
- 对的对的，哦不对不对 (`right_then_wrong`)：有限次数制造从对到错。
- 过程分 (`process_points`)：交替中出现错题时减少损失。

注意：

- 该流派目前只有两张直接收益核心卡，可以保留为 tag，但权重不宜过高。

## 销毁抽取流

收益逻辑：通过增加抽取、随机获得、销毁遗物、失去遗物收益、遗物上限变化，形成遗物经济循环。

核心卡：

- 多选题 (`multiple_choice`)
- 无中生有 (`create_from_nothing`)
- 上线立送10连抽 (`ten_pull_gift`)
- 我们可以改变一切 (`change_everything`)
- 白银狮子 (`silver_lion`)
- 心外无物 (`no_external_things`)
- 轻装上阵 (`travel_light`)

次要卡：

- 废话文学大师 (`nonsense_master`)：吃无效遗物数量，和抽取量相关。
- 上海卷高考作文 (`shanghai_essay`)：可作为废话文学大师素材。
- 说的道理 (`reasonable_reason`)：可作为废话文学大师素材。
- 小丑牌 (`tiny_joker`)：可作为废话文学大师素材。
- 百日誓师 (`hundred_day_oath`)：可作为废话文学大师素材。

建议：

- `抽取`、`消耗`、`销毁` 不建议拆成独立 tag。它们最好合并为一个稳定构筑方向：`销毁抽取流`。

## 豌豆连招流

收益逻辑：其他遗物触发后，复制、连锁、触发右侧遗物，扩大触发次数；和“能连起来就是招”形成直接收益闭环。

核心卡：

- 双发射手 (`repeater`)
- 机枪射手 (`gatling_peashooter`)
- 瓷砖萝卜 (`tile_turnip`)
- 电能机枪豌豆 (`electric_gatling_pea`)
- 模仿者 (`imitator`)
- 能连起来就是招 (`chain_is_method`)

次要卡：

- 幸运方块 (`lucky_block`)：被连招触发体系放大时收益很高，但本身随机。
- 再生药水 (`regeneration_potion`)：稳定题末触发，可作为连招触发源。
- 至终的仪式 (`final_ritual`)：题末触发源，但依赖连胜。
- 过程分 (`process_points`)：错题时题目计分触发源，可增加本题触发次数。

建议：

- `豌豆` 和 `联动` 不建议拆开。更清晰的正式 tag 是 `豌豆连招流`。

## 体力流

收益逻辑：通过补体力、锁体力下限、利用高体力或低体力阈值，让正确率或倍率收益稳定化。

核心卡：

- 体力药水 (`stamina_potion`)
- 再生药水 (`regeneration_potion`)
- 名刀·司命 (`death_blade`)
- 精力充沛 (`energetic`)
- 红骷髅 (`red_skull`)

次要卡：

- 玻璃大炮 (`glass_cannon`)：消耗体力换倍率，适合有体力补给时使用。
- 深度思考中 (`deep_thinking`)：消耗体力换正确率，适合体力流支撑。
- 轮回之终末 (`final_reincarnation`)：极端体力与正确率，但有强负面。

注意：

- `续航` 不建议作为独立 tag，可并入 `体力流`。

## 分数形态流

收益逻辑：操纵或利用考试原始分数字形态，触发平方、立方、回文、重复数字、连续数字等奖励。

核心卡：

- 数学爱好者 (`math_lover`)
- C语言大佬 (`c_language_master`)
- 欢乐小丑 (`happy_clown`)
- 滑稽小丑 (`slippery_clown`)
- 狂小丑 (`crazy_clown`)
- 回文数 (`palindrome_score`)
- 宇宙立方 (`tesseract`)
- 唉，二次元 (`weeb_square`)

次要卡：

- 过程分 (`process_points`)：小额改变原始分，可能影响数字形态。
- 空城 (`empty_city`)：极端情况下把原始分拉到满分，可参与形态判断。
- 正确率流核心卡：稳定原始分区间，让数字操作更可控。

建议：

- `操作分数` 不建议独立成 tag，应并入 `分数形态流`。

## 无效遗物流

收益逻辑：通过收集无效果遗物，让废话文学大师按数量转化为考试最终分数。

核心卡：

- 废话文学大师 (`nonsense_master`)

次要卡：

- 上海卷高考作文 (`shanghai_essay`)
- 说的道理 (`reasonable_reason`)
- 小丑牌 (`tiny_joker`)
- 百日誓师 (`hundred_day_oath`)

注意：

- 该流派核心收益只有一张卡，稳定性弱于正确率、连胜、错题连败、销毁抽取、豌豆连招。
- 可以保留为小流派 tag，但不建议让它过强影响抽取权重。

## 暂不建议作为正式稳定流派 Tag

这些更像机制、位置、收益类型或辅助描述，不适合参与同 tag 抽取加权：

- `分数补偿`：收益类型，不是构筑方向。
- `倍率成长`：收益类型，分散在正确率、连胜、错题、体力等流派中。
- `考试倍率`：收益类型，不是稳定流派。
- `总分成长`：卡量少，多为单次收益。
- `压轴题`：位置条件。
- `前期题`：位置条件。
- `节奏题`：触发节奏条件。
- `容量`：单卡机制。
- `容错`：辅助属性。
- `风险收益`：风险属性，不是稳定收益流派。
- `随机爆发`：高方差，不稳定。
- `幸运方块`：当前是专属组件，但稳定性不足，暂不升格。
- `抽取`、`消耗`、`销毁`：建议合并为 `销毁抽取流`。
- `豌豆`、`联动`：建议合并为 `豌豆连招流`。
- `续航`：建议并入 `体力流`。
- `操作分数`：建议并入 `分数形态流`。

## 建议的下一步改法

如果按本文档改数据，建议把每张遗物的正式流派 tag 控制在 1 到 2 个：

- 主 tag：它最主要服务的稳定流派。
- 副 tag：只有当它能明显支持另一个稳定流派时才加。

例如：

- `过程分`: `错题连败流`, `豌豆连招流`
- `圣水采集器`: `正确率流`
- `快乐小花`: `正确率流`, `连胜流`
- `无中生有`: `销毁抽取流`
- `电能机枪豌豆`: `豌豆连招流`
- `废话文学大师`: `无效遗物流`, `销毁抽取流`
