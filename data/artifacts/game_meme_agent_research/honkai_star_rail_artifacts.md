### 抽取与失去机制

第九十发的录取通知:
出处: Character Event Warp / 角色活动跃迁
原描述: 限时角色跃迁含1名概率提升5星角色与3名概率提升4星角色。基础概率为5星角色0.6%、4星角色或光锥5.1%、3星光锥94.3%。连续9抽未出4星及以上时, 第10抽必出4星及以上; 每次获得4星时有50%概率为当期UP 4星, 若歪则下一次4星必为UP。连续89抽未出5星时, 第90抽必出5星; 角色池5星掉落一定为角色。每次获得5星时有50%概率为当期UP 5星, 若歪则下一次5星必为UP; 最多180抽保底获得当期UP 5星。计数与大保底继承到下一个同类型角色活动跃迁。
遗物效果: 每连续89题未触发高分判定, 第90题正确率+1000%; 若该次没有命中"第一志愿", 下一次高分判定必定命中, 且跨考试继承计数
来源链接: https://honkai-star-rail.fandom.com/wiki/Character_Event_Warp

四十票的新生池准考证:
出处: Departure Warp / 始发跃迁
原描述: 新手跃迁卡池总计50抽后自动消失。十连享20%折扣, 每10抽只需8张星轨通票。每10抽至少获得1个4星或以上物品; 50抽内保证随机获得1名5星常驻角色。
遗物效果: 开局前5次三选一只消耗8点体力视为10连; 第50题前必定获得1张额外遗物, 触发后本遗物销毁
来源链接: https://honkai-star-rail.fandom.com/zh/wiki/始发跃迁

量子大乐透铅笔盒:
出处: Curio Quantum Big Lotto / 奇物「量子大乐透」
原描述: 模拟宇宙/差分宇宙奇物。未知域版本: 击碎可破坏物后, 有小概率获得1个随机组件, 但也有小概率直接损坏该奇物, 并使全队损失99%当前生命值、全部能量与全部秘技点。差分宇宙版本: 击碎可破坏物后, 有小概率获得1个负面奇物, 也有小概率损坏该奇物; 损坏时获得400宇宙碎片。
遗物效果: 每次遇到"可跳过题"时可选择击碎; 20%概率获得1张临时遗物, 10%概率体力变为当前的1%、清空所有本场倍率并销毁本遗物
来源链接: https://honkai-star-rail.fandom.com/wiki/Quantum_Big_Lotto

### 题号触发

停转的早八萨尔索图:
出处: Planar Ornament Inert Salsotto / 停转的萨尔索图
原描述: 位面饰品遗器套装, 2-5星稀有度, 1.0版本发布。二件套效果为暴击率提高8%; 当装备者当前暴击率>=50%时, 终结技与追加攻击造成的伤害提高15%。
遗物效果: 基础正确率+8%; 若当前题正确率>=50%, 每场考试第10题与第15题得分倍率+1.15
来源链接: https://honkai-star-rail.fandom.com/zh/wiki/停转的萨尔索图

拂晓之前的五三:
出处: 5星智识光锥 Before Dawn / 拂晓之前
原描述: 智识命途5星光锥。叠影1/5时分别使装备者暴击伤害提高36%/60%, 战技与终结技造成的伤害提高18%/30%; 当装备者施放战技或终结技后获得「梦身」, 触发追加攻击时消耗「梦身」, 使该次追加攻击造成的伤害提高48%/80%。
遗物效果: 每场考试第1次触发"压轴题"或"追加题"时, 获得梦身; 下一次其他遗物追加触发时, 该追加触发的加分提高48%
来源链接: https://honkai-star-rail.fandom.com/zh/wiki/拂晓之前

### 题目属性触发

繁星璀璨的压轴题:
出处: Relic Set Genius of Brilliant Stars / 繁星璀璨的天才
原描述: 遗器套装, 2-5星稀有度, 1.0版本发布。二件套使量子属性伤害提高10%; 四件套在装备者对目标造成伤害时无视目标10%防御, 若目标具有量子弱点, 则额外无视10%防御。
遗物效果: 需要题目属性: 偏门题。偏门题得分倍率+0.1; 若该题同时标记"弱点", 本题正确率惩罚减少20%
来源链接: https://honkai-star-rail.fandom.com/wiki/Genius_of_Brilliant_Stars

弱点击破草稿纸:
出处: Toughness / Weakness Break 韧性与弱点击破
原描述: 韧性是敌方专属属性; 使用与敌方弱点对应的属性攻击可削减韧性。韧性归零时触发弱点击破: 造成一次击破伤害, 使敌方行动延后25%, 并以150%基础概率施加与触发属性对应的减益, 同时进入弱点击破状态。敌方在其下一个回合恢复韧性。击破伤害受击破特攻、目标最大韧性、角色等级等影响, 不会暴击, 也不受常规增伤与暴击乘区影响。
遗物效果: 若题目属性与上一题相同且上一题答对, 本题正确率+25%; 若本题仍答对, 下一题体力下降延后1题结算
来源链接: https://honkai-star-rail.fandom.com/wiki/Toughness

### 终局玩法

混沌回忆答题卡:
出处: Forgotten Hall / Memory of Chaos 忘却之庭·混沌回忆
原描述: 混沌回忆为高难常驻轮换内容, 每6周刷新一次, 敌方等级约68-95。每层包含2个节点、每节点1场战斗, 共享30个回合上限。三星条件为: 至少剩余12回合、至少剩余18回合、且全队无人倒下。每期全层共用同一条记忆紊流, 通常在每个新Cycle开始时触发。
遗物效果: 每场考试限30次遗物触发预算; 若结束时触发次数剩余>=12, 本场考试分数+30; 剩余>=18再+30; 体力未归零再+30
来源链接: https://honkai-star-rail.fandom.com/wiki/Forgotten_Hall

虚构叙事作文格:
出处: Pure Fiction / 虚构叙事
原描述: 虚构叙事每6周刷新一次, 为分数制玩法, 面对会持续补充的敌人。每期共4关, 敌方等级依次为55/65/75/85; 每关含2个节点, 每节点可选1个三选一增益。节点为三波战斗, 非首领敌人会持续补位; Wave 1通过击败20个敌人推进, Wave 2/3则通过击杀补位怪对目标施加真伤。每节点满分40000, 全关总分上限80000。
遗物效果: 每场考试每答对5题进入下一波; 选择题每答对1题额外+4分, 但本场考试最多额外+80分
来源链接: https://honkai-star-rail.fandom.com/wiki/Pure_Fiction

### 联动

烦恼着，幸福着的估分表:
出处: 5星巡猎光锥 Worrisome, Blissful / 烦恼着，幸福着
原描述: 巡猎命途5星光锥。叠影1/5时分别使装备者暴击率提高18%/30%, 追加攻击伤害提高30%/50%。装备者施放追加攻击后, 使目标陷入「温驯」状态, 最多叠加2层; 我方目标击中处于「温驯」状态的敌方目标时, 每层使造成的暴击伤害提高12%/20%。
遗物效果: 基础正确率+18%; 每次其他遗物追加触发后, 给下一题1层温驯, 最多2层; 每层使下一题高分加成+12%
来源链接: https://honkai-star-rail.fandom.com/zh/wiki/烦恼着，幸福着
