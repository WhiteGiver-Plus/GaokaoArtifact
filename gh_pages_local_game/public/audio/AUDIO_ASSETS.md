# Audio Assets

All files in this folder were selected for lightweight web-game use. Prefer these files over the original source packs to keep the deployed asset size small.

## BGM

| File | Suggested use | Source | License |
| --- | --- | --- | --- |
| `bgm/happy-synths-loop.ogg` | Main playful loop; light, nimble, bell/synth feeling | OpenGameArt: Happy synths loop with slight christmas feeling | CC0 |
| `bgm/keep-your-dream-alive-loop.ogg` | More energetic chiptune loop; good for high-score/endless mode | OpenGameArt: Keep your dream alive! seamless loop | CC0 |
| `bgm/upbeat-chiptune-theme.ogg` | Fast retro loop; good for intense auto-grading | OpenGameArt: Upbeat chiptune theme | CC0 |
| `bgm/upbeat-title-theme-loop.ogg` | Softer title/menu loop | OpenGameArt: Upbeat Title Theme Loop | CC0 |
